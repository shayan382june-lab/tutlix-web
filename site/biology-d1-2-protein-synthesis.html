⚡ D1.2 in 60 seconds

  1. Transcription: RNA polymerase builds mRNA from the DNA template strand (nucleus).
  2. Translation: ribosomes read mRNA codons; tRNA anticodons bring amino acids.
  3. The code is universal and degenerate; AUG = start; 3 stop codons.
  4. One base change → one amino acid change (e.g. sickle cell, Glu→Val).
  5. HL: 5′→3′; promoters; introns spliced out; alternative splicing.
  6. HL: polypeptide modification (insulin) and proteasome recycling.

D1.2.1 – D1.2.3

Transcription

  • Transcription is the synthesis of RNA using a DNA template. It happens in the nucleus (eukaryotes).
  • RNA polymerase binds to DNA, separates the two strands (breaking hydrogen bonds) and links free RNA nucleotides.
  • Only one strand is transcribed: the template strand. The other is the coding (sense) strand, which has the same sequence as the mRNA (but T instead of U).
  • Complementary base pairing (A–U, T–A, C–G, G–C) ensures the RNA sequence is determined by the DNA.
  • Stability of DNA: DNA template sequences are kept stable (double helix, sugar–phosphate backbone), so genes can be transcribed many times without being damaged.
  • Transcription allows gene expression: in each cell type, only some genes are transcribed.
